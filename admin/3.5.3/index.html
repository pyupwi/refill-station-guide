01 / GETTING STARTED

기기 사용 시작하기

전원을 켜면 설정된 시작 화면이 열립니다. 고객에게 제공할 때는 디스펜스 화면을 사용합니다. 기기 버전은 홈 → 관리 → 시스템 화면 아래의 제품 정보에서 확인합니다.

관리 화면으로 들어가기

  1. 홈으로 이동합니다.

    디스펜스 화면 오른쪽 위 모서리를 3초 안에 5번 탭합니다. 페이지가 잠겨 있다면 비밀번호를 입력합니다.

  2. 홈의 관리를 누릅니다.

    관리자 잠금이 켜져 있다면 설치 시 지정한 관리자 비밀번호를 입력합니다.

  3. 왼쪽 목차에서 설정 항목을 선택합니다.

    관리 화면은 잔량 항목으로 시작합니다. 보정은 캘리브레이션, 고객 화면은 디스펜스, 접근 설정은 시스템에서 관리합니다.

홈에서 할 수 있는 일

항목사용 방법
리필 시작 / 펌프 정지홈의 수동 출력을 켜고 끕니다. 받을 용기를 먼저 준비하고, 원하는 양에서 펌프 정지를 누릅니다.
프리셋미리 저장한 양을 선택해 리필합니다. 버튼을 누르면 바로 시작하므로 용기를 먼저 놓습니다.
수동숫자 입력 화면에서 이번 리필량과 단위를 확인하고 확정합니다. 이름이 비슷한 캘리브레이션의 수동 보정과는 별도 기능입니다.
디스펜스고객용 화면을 엽니다. 중앙 숫자가 목표량이며, 스와이프 허용 여부와 시작 확인은 매장 설정을 따릅니다.
예상 리필량 / 누적 리필현재 또는 직전 동작의 예상량과 누적 사용량을 확인합니다. 표시량은 저장된 보정값으로 계산한 값입니다.
재부팅기기를 다시 시작합니다. 진행 중인 출력이 끝나고 펌프가 멈춘 것을 확인한 뒤 사용합니다.
일시정지와 종료

리필 진행 화면을 탭하면 일시정지합니다. 계속하려면 리필재개, 이번 리필을 끝내려면 빨간 정지를 누릅니다. 펌프 오류 화면에서는 표시된 오류를 확인하고 이전으로 돌아갑니다.

02 / DAILY OPERATION

매장 운영 순서

영업 시작 전

  • 제품명, 말통의 내용물, 사용 기한과 제품 상태를 확인합니다.
  • 튜브 꺾임, 느슨한 연결, 노즐 막힘과 새는 곳이 없는지 확인합니다.
  • 실제 말통 상태와 예상 잔량을 대조합니다. 새 말통은 말통 교체, 부분 사용한 말통은 잔량 보정으로 반영합니다.
  • 현재 사용할 보정과 고객에게 제공할 리필량을 확인합니다.
  • 받을 용기를 준비해 시험 리필을 하고, 정지·마무리와 실제 배출량을 확인합니다.
  • 고객용 디스펜스 화면으로 돌아갑니다.

운영 중과 마감

잔량 표시는 보충 시점을 판단하는 참고값입니다. 실제 말통도 함께 확인하고, 공기가 섞이거나 토출이 불규칙하면 고객 사용을 멈춥니다. 마감할 때는 진행 중인 리필을 끝내고 펌프 정지를 확인한 뒤 노즐과 주변을 정리합니다.

제품, 튜브, 노즐, 펌프 또는 출력 설정을 바꿨다면 시험 리필로 양을 다시 확인하고 필요하면 재보정합니다.

03 / CALIBRATION

캘리브레이션

홈 → 관리 → 캘리브레이션

실제로 배출된 양을 기기에 알려 주어, 목표량에 맞는 펌프 동작 시간을 계산하게 하는 작업입니다. 측정 → 실측량 입력 → 저장 → 사용할 보정 선택 순서로 진행합니다.

시작 전 준비

실제 운영할 제품·튜브·노즐·출력 설정으로 준비합니다. 받을 용기는 충분히 크게 잡고, 배출된 내용물만의 양을 측정할 수 있게 빈 용기 값을 제외합니다. 화면이 g이면 무게를 g으로, mL이면 부피를 mL로 측정해 입력합니다.

액체 흐름이 고르지 않거나 공기가 섞인 상태의 결과로 보정하지 마세요. 각 회차가 끝나면 남은 방울까지 받은 뒤 그 회차의 실측량을 기록합니다.

방식측정 방법저장되는 보정
간편 보정설정된 시간 동안 1회 배출. 기본 5초.단일 R
수동 보정직접 시작하고 원하는 양에서 측정 완료.단일 R
정밀 보정두 시간 × 각 3회, 총 6회 측정.정밀 보정값

R은 1초 동안 배출되는 양입니다. 간편·수동 보정은 하나의 R을 저장하고, 정밀 보정은 서로 다른 두 시간에서 측정한 결과를 이용합니다. 정밀 보정이라는 이름이 특정 오차 범위를 보장하는 것은 아니므로 실제 운영량으로 확인합니다.

간편 보정

  1. 측정 시간을 확인합니다.

    관리 → 정확도 → 캘리브 시간에서 확인합니다. 기본 5초이며, 변경한 값이 있으면 그 시간을 사용합니다.

  2. 용기를 놓고 간편 보정을 누릅니다.

    펌프가 작동하고 남은 시간이 표시됩니다. 설정 시간이 끝나면 자동으로 멈춥니다.

  3. 실측량을 입력합니다.

    배출이 완전히 끝난 뒤 내용물만의 양을 측정합니다. 실측량 입력 화면에 해당 숫자를 넣고 확정합니다.

  4. 메모와 함께 저장합니다.

    제품·노즐 등 조건을 보정 메모에 남기고 메모와 저장을 누릅니다. 메모가 필요 없으면 메모 없이 저장을 누릅니다. 저장 실패가 표시되면 완료된 것으로 판단하지 않습니다.

  5. 단일 R 사용을 선택합니다.

    캘리브레이션 첫 화면에서 현재 R과 기록을 확인합니다. 이 보정으로 운영하려면 단일 R 사용을 누릅니다.

R = 이번 실측량 ÷ 실제 펌프 동작 시간예: 실제 동작 5초 동안 100 g이 배출됐다면 R은 20 g/s입니다. 기기는 실제로 계측한 동작 시간을 사용합니다.

수동 보정

정해진 시간 대신, 작업자가 적당한 양에서 측정을 마칠 때 사용합니다.

  1. 용기를 놓고 수동 보정을 누릅니다.

    펌프가 작동하며 경과 시간이 표시됩니다. 작업 중 자리를 지키세요.

  2. 원하는 양에서 측정 완료를 누릅니다.

    펌프가 멈춘 뒤 남은 액체까지 받습니다. 화면의 뒤로/취소는 정상 측정 완료를 대신하지 않습니다.

  3. 실측량을 입력하고 저장합니다.

    내용물만의 양을 입력한 뒤 메모와 저장 또는 메모 없이 저장을 선택합니다.

  4. 단일 R 사용을 선택하고 확인합니다.

    간편 보정과 같은 단일 R을 갱신합니다. 정밀 보정을 사용 중이었다면 저장만으로 사용 선택이 바뀌지는 않습니다.

정밀 보정 · 총 6회 측정

짧은 시간과 긴 시간에서 각각 세 번 측정합니다. 기기는 각 그룹의 중앙값을 사용합니다. 세 값을 작은 순서로 놓았을 때 가운데 값이며, 평균값과 다릅니다.

1번 시간 · 기본값3초 × 3회

1/6 → 2/6 → 3/6

2번 시간 · 기본값10초 × 3회

4/6 → 5/6 → 6/6

  1. 정밀 보정을 열고 프로파일을 선택합니다.

    프로파일 1~4 중 이번 측정을 보관할 곳을 선택합니다. 기존 결과를 남기려면 다른 프로파일을 사용합니다.

  2. 두 시간을 설정합니다.

    각 시간 버튼을 눌러 수정합니다. 각각 0.1~60초이며 서로 다른 값이어야 합니다. 두 시간 모두 용기가 넘치지 않도록 정합니다. 액체·튜브 번호는 조건을 구분하는 기록용으로 사용할 수 있습니다.

  3. 1/6 측정 시작을 누릅니다.

    용기를 놓고 화면에 표시된 시간을 확인한 뒤 시작합니다. 자동으로 정지하고 남은 액체까지 받은 뒤, 이번 회차의 실측량만 입력합니다.

  4. 2/6부터 6/6까지 같은 방식으로 반복합니다.

    매번 용기를 비우거나 새 용기를 준비하고, 각 회차를 직접 시작합니다. 4/6부터는 두 번째 시간을 사용합니다. 누적된 총량을 입력하지 마세요.

  5. 마지막 입력 후 저장 완료를 확인합니다.

    6번째 실측량을 확정하면 정밀 보정값을 자동 계산·저장합니다. 6/6 기록과 저장됨 표시를 확인합니다. 추가 측정 시작은 새 6회 측정을 시작하는 동작입니다.

  6. 캘리브레이션 첫 화면에서 정밀 보정 사용을 누릅니다.

    정밀 보정 상세 화면에서 돌아와 사용할 모델을 선택합니다. 원하는 프로파일의 값이 준비되어 있는지 확인한 뒤 선택하고 시험 리필을 합니다.

정지와 취소를 구분하세요.

정밀 측정 중 왼쪽 정지를 누르면 이번 회차만 취소되고 이전 회차 기록은 남습니다. 펌프가 멈춘 것을 확인하고 정밀 보정을 다시 열어 같은 회차를 측정합니다.

뒤로/취소로 세션을 나가거나, 측정 도중 프로파일·시간을 바꾸면 미완료 회차를 이어 쓸 수 없습니다. 재부팅해도 미완료 측정은 이어지지 않습니다. 필요한 6회 측정을 한 세션에서 마치세요.

정밀 보정은 어떻게 계산하나요?

두 시간 T1·T2의 중앙값을 각각 M1·M2라고 하면 아래와 같이 계산합니다. 시간은 초, 양은 선택한 표시 단위 기준입니다.

a = (M2 − M1) ÷ (T2 − T1)
b = M1 − a × T1
목표량에 필요한 시간 = (목표량 − b) ÷ a

예를 들어 3초의 측정값이 58·60·62 g, 10초의 측정값이 198·200·202 g이면 중앙값은 60 g과 200 g입니다. 이때 a = 20 g/s, b = 0 g입니다.

측정 범위 밖에서도 같은 계산식을 사용합니다. 실제로 판매하는 작은 양과 큰 양을 별도로 확인하세요. 계산 또는 저장 오류가 표시되면 원래 보정값이 유지되므로 오류를 해결한 뒤 다시 저장합니다.

사용할 보정 선택과 검증

보정값을 저장하는 일과 실제 사용할 보정을 고르는 일은 별개입니다. 캘리브레이션 첫 화면의 단일 R 사용 또는 정밀 보정 사용 버튼으로 선택합니다. 저장된 정밀값이 없는 프로파일은 정밀 보정 사용 버튼이 비활성화됩니다.

  1. 현재 보정 검증 (선택)을 엽니다.

    검증할 보정을 먼저 선택합니다. 진행 중인 정밀 측정이 있다면 완료하거나 취소하고 엽니다.

  2. 검증 시간을 선택합니다.

    15초·30초·60초 버튼 또는 직접 입력을 사용합니다. 긴 시간일수록 배출량이 커지므로 받을 용기를 먼저 확인합니다.

  3. 검증 시작을 누르고 실측량을 입력합니다.

    정지가 끝난 뒤 내용물만의 양을 측정해 입력합니다. 화면에서 예상량, 실측량, 차이와 오차율을 비교합니다.

  4. 결과를 보고 다음 작업을 선택합니다.

    그대로 운영하려면 현재 보정 그대로 사용을 누릅니다. 다시 캘리브레이션을 누르면 보정 화면으로 돌아가므로 원하는 보정 방식을 다시 선택합니다.

차이는 실측량 − 예상량입니다. 양수면 예상보다 많이, 음수면 적게 나왔다는 뜻입니다. 이 검증은 보정값이나 사용 선택을 자동으로 바꾸지 않으며, 합격/불합격을 자동 판정하지 않습니다.

검증 화면은 선택한 보정의 계산을 비교합니다. 고객 화면의 미세 조정까지 포함한 최종 결과는 실제 디스펜스 리필로 별도 확인하세요.

동작결과와 확인할 점
단일 토출 검사 → 사용해당 기록의 R을 현재 단일 R로 복원합니다. 운영에도 적용하려면 단일 R 사용을 확인합니다.
첫 화면 → 삭제확인창에서 승인하면 단일 보정 기록 목록을 지웁니다. 정밀 프로파일 삭제와는 별도입니다.
프로파일 선택보거나 측정할 정밀 프로파일을 바꿉니다. 선택만으로 실제 운전에 적용되지는 않습니다. 사용하려면 정밀 보정 사용을 누릅니다.
정밀 상세 → 삭제선택한 프로파일의 정밀값을 삭제합니다. 해당 정밀값이 사용 중이면 단일 R로 전환됩니다. 이 화면의 삭제는 별도 확인창 없이 실행되므로 대상을 먼저 확인합니다.

정밀값 삭제 후 단일 R도 없다면 고객용 운영을 재개하기 전에 보정부터 수행합니다. 기록 삭제, 정밀값 삭제, 전체 기기 초기화는 서로 다른 작업입니다.

05 / PRODUCT & USAGE

잔량과 누적 리필

홈 → 관리 → 잔량

예상 잔량은 말통에 남았다고 계산한 양이고, 누적 리필은 기기가 집계한 리필 사용량입니다. 서로 다른 값입니다.

새 말통으로 교체할 때

  1. 출력을 멈추고 말통을 교체합니다.

    새 제품과 연결 상태를 확인합니다. 제품 교체 시 취급·세척 기준도 함께 적용합니다.

  2. 말통 교체를 누릅니다.

    입력 화면의 kg 단위에 맞춰 내용물 양을 입력합니다. 예를 들어 20 kg은 20으로 입력합니다. 말통 자체 무게는 포함하지 않습니다.

  3. 새 잔량을 확인합니다.

    입력한 양이 용량과 잔량의 새 기준이 됩니다. 일부 사용한 말통이라면 이어서 잔량 보정으로 실제 남은 양을 맞춥니다.

표시 잔량을 맞출 때

잔량 보정을 누르고 현재 남아 있는 내용물의 양을 kg 단위로 입력합니다. 보충한 양을 더하는 입력이 아니라, 현재 잔량 자체를 지정하는 입력입니다.

전원을 다시 켠 뒤에는 실제 잔량을 대조하세요.

현재 버전의 사용 중 잔량 차감은 매번 영구 저장되지 않습니다. 말통 교체·잔량 보정은 저장되지만 재부팅 후 표시가 직전 실제 잔량과 다를 수 있으므로, 필요하면 잔량 보정으로 맞춥니다.

누적 리필 초기화 · 3.5.3

필요한 누적값을 따로 기록한 뒤 누적 리필 → 초기화를 누릅니다. 확인창에서 초기화를 선택하면 0으로 바뀌고, 취소하면 유지됩니다. 누적값만 초기화하며 말통 잔량과 보정값을 지우는 기능은 아닙니다. 저장된 누적값은 재부팅 후에도 유지됩니다.

보정·검증에 사용한 액체는 예상 잔량에서 차감될 수 있지만, 고객 리필 누적과는 집계 목적이 다릅니다. 누적값을 실제 재고나 거래 내역으로 단정하지 마세요.

07 / OUTPUT & CONNECTION

펌프 출력과 연결

홈 → 관리 → 펌프 출력

이 항목은 기기와 펌프의 설치 구성에 맞추는 설정입니다. 기존 설치값을 기록하고, 배선이나 구동 방식이 달라진 경우 설치 담당자가 확인한 값으로 설정합니다.

출력 위치와 신호

출력 위치에서 GPIO, CH422G, ESP-NOW 중 설치 구성에 해당하는 방식을 선택합니다. 프리셋 도우미의 릴레이·MOSFET·H-bridge는 설정의 시작값을 채우는 기능이며, 실제 배선을 확인해 주는 기능이 아닙니다.

  1. 출력 신호 → 열기로 들어갑니다.

    설치에 맞는 신호 수, Signal A/B와 정지·정방향 등의 패턴을 확인합니다. 핀 번호나 신호 레벨은 다른 기기의 값을 그대로 복사하지 않습니다.

  2. 용기를 준비하고 테스트합니다.

    테스트는 실제 펌프 출력을 동작시킵니다. 작동 방향과 정지를 직접 확인하고 테스트를 끝낼 때 정지를 누릅니다. 자동으로 끝나기를 기다리지 마세요.

  3. 정지 후 저장합니다.

    로컬 출력은 화면에서 테스트가 성공해야 저장할 수 있습니다. 저장 오류를 확인하고, 설정을 다시 열어 확인합니다. 출력을 바꿨다면 보정도 다시 점검합니다.

출력 신호 항목 읽기

신호 수 / Signal A·B는 사용할 제어 신호와 번호입니다. 정지·정방향·역방향 패턴은 각 상태에서 낼 신호를 정합니다.

PWM / 기본 듀티 / PWM 주파수는 해당 출력 구성이 지원하는 경우에만 사용합니다. 정상 토출 방향은 리필할 때의 방향, 방향 전환 대기는 방향을 바꾸는 사이의 정지 간격입니다. 지원하지 않는 동작이나 오류가 나오면 다른 값으로 반복 실행하지 말고 설치 구성을 확인합니다.

펌프 리시버 연결

ESP-NOW 연결 → 관리에서 리시버를 확인합니다. 검색으로 발견한 기기를 선택하거나, 설치 담당자가 제공한 식별값으로 수동 추가합니다. 리시버 이름은 현장 구분에 맞게 지정하고, 사용할 리시버만 ON으로 둡니다. 전체 해제는 등록된 연결을 지우므로 교체 작업에 필요한 경우에만 사용합니다.

연결을 바꾼 뒤에는 해당 펌프가 실제로 움직이고 정지하는지 확인합니다. 목록에 이름이 보이는 것만으로 정상 토출이 확인되는 것은 아닙니다.

제품 회수

역방향 회수가 가능한 설정이면 홈에 제품 회수가 나타납니다. 이 버튼으로 회수 모드에 들어간 뒤 노란 회수 시작을 누릅니다. 회수 경과 시간을 보며 작업하고, 마치려면 펌프 정지를 누릅니다. 제품 회수는 자동 종료 시간이 없으므로 작업자가 지켜보며 직접 종료합니다.

버튼이 보이지 않으면 현재 구성에서 제공되지 않는 기능입니다. 회수한 내용물의 재사용 여부는 제품의 위생·취급 기준에 따라 판단합니다.

Wi-Fi 연결 설정 · 3.5.3

홈 → 관리 → 무선 통신

공유기 연결이 필요한 설치에서는 스캔으로 네트워크를 선택하고 해당 연결 정보를 입력·저장합니다. 설정값 대신 화면의 실제 연결 상태를 확인합니다. 해제는 저장된 공유기 연결 정보를 지우는 작업입니다.

아래쪽 Wi-Fi 끄기는 기기의 AP와 공유기 접속을 끄는 설정입니다. 다시 사용하려면 Wi-Fi 켜기를 누릅니다. 펌프 리시버 통신은 별도로 유지하도록 구성되어 있습니다. 네트워크를 변경한 뒤에는 리시버의 실제 작동·정지도 함께 확인합니다.

08 / SYSTEM

시스템과 잠금

홈 → 관리 → 시스템

항목의미
시작 화면전원을 켰을 때 열릴 화면입니다. 고객용으로 운영할 때는 디스펜스를 선택합니다.
관리자 잠금홈에서 관리 화면에 들어갈 때 비밀번호를 요구합니다.
페이지 잠금 / 잠글 페이지특정 이용 화면에서 홈 등 다른 화면으로 빠져나가는 접근을 제한합니다. 잠글 페이지를 선택한 뒤 저장합니다.
비밀번호관리자 접근에 사용할 비밀번호를 변경합니다. 지정한 값을 현장 관리자가 보관합니다.

메뉴 숨김은 화면 표시를 정리하는 기능입니다. 해당 기능의 값을 지우거나 비밀번호 보호를 대신하지 않습니다. 시작 화면과 잠글 페이지도 각각 별도로 지정합니다.

페이지 잠금 해제 후 고객에게 돌려줄 때

페이지 잠금을 해제한 세션은 재부팅 전까지 유지됩니다. 고객용 잠금 상태로 다시 시작해야 할 때는 출력을 멈추고 재부팅한 뒤 시작 화면과 접근 제한을 확인합니다.

공장 초기화

공장 초기화 → 확인창의 초기화는 기기 설정을 지우고 다시 시작하는 작업입니다. 단순 재부팅이나 누적값 초기화와 다릅니다. 필요한 설치값·보정값·잔량을 먼저 기록하고 수행합니다. 이후 출력, 보정, 잔량과 고객용 설정을 다시 준비한 뒤 사용합니다.

09 / CARE

제품 취급과 관리

노즐·튜브·제품

  • 제품 표시사항에 맞는 용기와 부품을 사용하고 서로 다른 제품이 섞이지 않게 관리합니다.
  • 노즐이 고객 용기의 내용물이나 오염된 표면에 닿지 않도록 배치합니다.
  • 튜브가 눌리거나 꺾이지 않게 하고, 연결부 누출·변색·경화·갈라짐이 있으면 사용을 멈추고 점검합니다.
  • 세척제, 농도, 온도, 세척 주기는 제품과 접액 부품 공급자의 지침을 따릅니다. 임의의 용제나 고온 세척 조건을 적용하지 않습니다.

청소·교체 전후

  1. 리필을 종료하고 펌프 정지를 확인합니다.

    튜브 분리나 부품 교체는 전원을 분리한 상태에서 합니다.

  2. 전장부와 제품이 닿는 부위를 구분해 정리합니다.

    화면·컨트롤러·전원부에 액체를 직접 분사하거나 담그지 않습니다. 제품이 닿는 부위는 해당 부품의 세척 지침을 따릅니다.

  3. 재연결 후 누출과 흐름을 확인합니다.

    시험 리필과 정지를 확인한 뒤 실제 배출량을 점검합니다. 조건이 바뀌었다면 다시 캘리브레이션합니다.

누출, 타는 냄새, 비정상적인 발열 또는 정지하지 않는 출력이 있으면 사용을 중단합니다. 액체가 묻은 전원부는 만지지 말고, 현장 안전 절차에 따라 전원을 차단하고 점검 담당자에게 알립니다.

10 / TROUBLESHOOTING

문제 해결과 로그

먼저 펌프를 정지하고, 화면 문구와 발생한 순서를 기록합니다. 같은 동작을 반복하거나 설정을 한꺼번에 바꾸기 전에 아래 항목을 확인합니다.

실제 리필량이 목표와 계속 달라요.

① 제품 흐름·튜브·노즐 상태 → ② 현재 선택된 단일 R/정밀 보정과 프로파일 → ③ 실측량의 단위와 빈 용기 제외 여부 → ④ 미세 조정값 순서로 확인합니다. 보정 검증과 실제 디스펜스 리필을 비교하고 필요하면 같은 운영 조건에서 다시 보정합니다.

정밀값을 저장했는데 토출이 그대로예요.

저장만으로 사용 모델은 바뀌지 않습니다. 원하는 프로파일을 확인하고 캘리브레이션 첫 화면에서 정밀 보정 사용을 누르세요. 프로파일을 보는 동작도 실제 사용 선택과 별개입니다.

정밀 보정 사용 버튼이 비활성화되어 있어요.

선택한 프로파일에 저장된 정밀값이 있는지 확인합니다. 6회 실측 입력과 마지막 저장까지 완료해야 합니다. 다른 프로파일에 저장했다면 그 프로파일을 선택합니다.

정밀 측정을 중간에 멈췄어요.

측정 중 정지로 멈췄다면 완료된 이전 회차 기록을 확인하고 같은 회차를 다시 시작합니다. 뒤로/취소, 설정 변경 또는 재부팅으로 세션을 끝냈다면 6회를 다시 측정합니다. 중단 회차의 양을 정상 측정값으로 넣지 마세요.

보정 중 오류나 저장 실패가 나와요.

펌프가 사용 중인지, 출력 설정이 맞는지 확인합니다. 정밀 시간은 서로 달라야 하며, 보정 실측량은 0보다 큰 값이어야 합니다. 마지막 입력에서 오류가 났다면 오류를 해결하고 다시 확정합니다. 저장됨 표시를 확인하기 전에는 새 값이 적용됐다고 판단하지 않습니다.

리필을 시작할 수 없거나 액체가 나오지 않아요.

진행 중인 출력·보정·테스트가 끝났는지, 말통·튜브·노즐 상태가 정상인지 확인합니다. 펌프 출력 위치와 활성 리시버, 현재 사용할 보정이 준비됐는지 확인합니다. 정지가 되지 않으면 고객 사용을 중단하고 현장 안전 절차를 따릅니다.

설정 메뉴가 사라졌어요.

관리 → 시스템 → 메뉴 숨김에서 해당 항목이 선택되어 있는지 확인하고 선택을 해제한 뒤 저장합니다. 시스템 메뉴는 숨겨지지 않습니다.

재부팅 뒤 잔량이 맞지 않아요.

사용 중 잔량 차감은 매번 영구 저장하지 않으므로 재부팅 전후 값이 다를 수 있습니다. 실제 남은 양을 확인하고 관리 → 잔량 → 잔량 보정으로 맞춥니다.

로그와 점검 요청

홈 → 관리 → 로그에서 최근 메시지를 확인합니다. INFO는 일반 정보, WARN은 주의, ERROR는 오류 메시지입니다. 점검에 필요한 메시지를 기록한 뒤에만 삭제합니다.

점검 요청에는 기기 버전, 발생 시각, 직전 조작, 화면 오류, 사용 제품, 목표량과 실측량, 선택한 보정·프로파일, 최근 변경한 설정을 함께 전달합니다. 비밀번호는 보내지 않습니다.

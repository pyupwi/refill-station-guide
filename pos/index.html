처음 설치한다면 아래 순서대로 성수점의 입구 세제 1대를 연결하고 100g 준비량을 확인하세요. 이어서 같은 매장의 두 번째 기기와 연남점을 추가합니다.

중앙 관리·기기 화면의 매장·기기·상품과 연결 키는 설명용 예시입니다. Toss 화면은 개발 테스트 앱·매장의 실제 화면이며, 자신의 매장 정보와 발급받은 키를 사용하세요.

1. 중앙 관리에 로그인하기

중앙 POS 관리 열기

  1. 계정 로그인에 받은 로그인 ID와 비밀번호를 입력하고 로그인을 누릅니다.
  2. 매장 관리자는 배정된 매장으로 바로 진입합니다. 화면 위의 매장 이름을 확인합니다.
  3. 전체 관리자는 현재 매장에서 작업할 매장을 선택합니다.

중앙 관리 계정은 전체 관리자에게 받습니다. 장치 등록 후 발급하는 연결 키와 기기 관리자 비밀번호는 각각 별도 정보입니다.

전체 관리자와 매장 관리자

전체 관리자는 매장 등록·수정·삭제, Toss 가맹점 연결, 계정 발급과 배정을 관리합니다. 매장 관리자는 배정된 한 매장의 모든 리필 장치·연결 키·상품 연결·테스트 주문·전달 대기를 관리합니다.

매장 계정 발급하기

  1. 전체 관리자 계정으로 로그인하고 계정 관리 → 계정 만들기를 누릅니다.
  2. 로그인 ID와 초기 비밀번호를 입력합니다. ID는 영문 소문자·숫자·점·밑줄·@·하이픈으로 3–64자, 비밀번호는 12–256자로 설정합니다.
  3. 권한: 매장 관리자와 해당 배정 매장을 선택하고 계정 만들기를 누릅니다.
  4. 계정 목록에서 ID·배정 매장·사용 중을 확인한 뒤 매장 담당자에게 로그인 정보를 전달합니다.

전체 관리자 계정이 필요하면 권한을 전체 관리자로 선택합니다. 같은 매장의 모든 기기는 해당 매장 계정으로 관리하고 다른 매장은 별도 계정을 발급합니다.

배정 변경·비밀번호 초기화·비활성화

  1. 계정 관리에서 해당 계정의 수정을 누릅니다.
  2. 다른 매장을 배정하려면 배정 매장을 바꿉니다. 권한을 바꾸려면 권한에서 전체 관리자 또는 매장 관리자를 선택합니다.
  3. 비밀번호를 초기화하려면 새 비밀번호를 입력합니다. 기존 비밀번호를 유지할 때는 비워 둡니다.
  4. 계정을 중지하려면 이 계정 사용을 해제합니다. 다시 사용할 때는 선택합니다.
  5. 변경 저장을 누르고 목록에서 변경한 매장과 사용 여부를 확인합니다.

저장하면 해당 계정은 다시 로그인해야 합니다. 기기 연결은 유지됩니다. 매장 담당자에게 바뀐 배정이나 새 비밀번호를 알려 주세요.

내 비밀번호 변경하기

  1. 본인 계정으로 로그인하고 비밀번호 변경을 누릅니다.
  2. 현재 비밀번호와 12–256자의 새 비밀번호를 입력합니다. 앞뒤 공백도 비밀번호에 포함됩니다.
  3. 비밀번호 변경을 누릅니다. 로그인 화면으로 돌아오면 본인 ID와 새 비밀번호로 로그인합니다.

변경하면 같은 계정으로 로그인한 모든 기기의 로그인이 해제됩니다. 현재 비밀번호를 잊었다면 전체 관리자에게 초기화를 요청하세요.

2. 성수점 등록하기

매장 등록과 Toss 가맹점 연결은 전체 관리자가 진행합니다. 매장 계정을 받았다면 배정된 매장 이름을 확인한 뒤 첫 번째 기기 등록으로 이동합니다.

  1. 왼쪽 매장 관리를 누르고 새 매장 등록을 엽니다. 첫 매장인 경우 매장 등록 버튼으로도 시작할 수 있습니다.
  2. 아래처럼 입력합니다.
입력칸 이번 예시에서 입력할 값
매장 이름 성수점
토스 가맹점 ID (MerchantId, 선택) 비워 둡니다. Toss 연결 단계에서 입력합니다.
  1. 매장 등록을 누릅니다.
  2. 왼쪽 현재 매장에 성수점이 선택되고 상단에도 성수점이 표시되는지 확인합니다.

이미 등록된 매장은 현재 매장에서 선택하면 됩니다. 이름이나 Toss 가맹점 ID를 바꾸려면 매장 관리 → 수정 → 변경 저장을 사용합니다.

3. 첫 번째 기기 등록하기

관리 목록에 기기 추가

  1. 현재 매장이 성수점인지 확인합니다.
  2. 리필 장치 → 장치 등록을 엽니다.
  3. 다음 값을 입력하고 장치 등록을 누릅니다.
입력칸 입력 예시
장치 이름 입구 세제
표시 단위 g · 무게

장치 이름은 관리자가 알아보기 쉽게 정하는 이름입니다. 설치 위치나 제품명을 붙이면 여러 기기를 구분하기 쉽습니다. mL로 운영하는 기기는 표시 단위를 mL · 부피로 선택하고 기기의 표시 단위도 맞춥니다.

주소와 연결 키 확보

등록하면 장치 연결 정보가 열립니다.

  1. 주소 복사를 눌러 서버 주소를 복사합니다.
  2. 키 복사를 눌러 입구 세제의 연결 키를 복사합니다.
  3. 연결 키를 성수점 / 입구 세제라는 이름으로 보관합니다.
  4. 확인했어요로 창을 닫고 리필 장치 목록에 입구 세제가 보이는지 확인합니다.
연결 정보 사용하는 값
서버 주소 https://refill.endet.xyz/api/device/sync
연결 키 이번에 입구 세제를 등록하면서 발급받은 키

서버 주소는 모든 기기가 공통으로 사용하고, 연결 키는 기기마다 따로 발급합니다. 키는 발급 창에서 한 번 표시되므로 보관 후 닫습니다.

4. 실제 입구 세제 기기에 연결하기

이제 성수점에 설치한 입구 세제 기기에서 설정합니다. 기기의 인터넷 연결과 기존 펌프 보정이 준비된 상태에서 진행하세요.

기기 Web으로 설정

  1. 해당 기기의 접속 주소를 열고 기기 관리자 비밀번호로 로그인합니다. 기기 주소는 장치의 접속 안내에서 확인합니다.
  2. 기기 설정 → POS 연동을 엽니다.
  3. 다음 값을 입력합니다.
입력칸 입력할 값
서버 주소 (HTTPS) https://refill.endet.xyz/api/device/sync
기기 연결 토큰 앞 단계에서 발급받은 성수점 / 입구 세제 키
POS 모드 사용 체크
  1. POS 설정 저장을 누릅니다.
  2. 저장 후 POS 모드 사용이 선택돼 있고 서버 주소가 유지되는지 확인합니다. 연결 토큰 입력칸은 보안을 위해 비워 표시되며, 입력칸 아래 연결 토큰 등록됨. 안내를 확인합니다.

Display 화면으로 설정

Display 기기는 관리 화면 → 무선 통신 → POS 연결에서도 설정할 수 있습니다.

저장 후 POS 대기 화면에 POS에서 상품을 선택하고 결제해 주세요가 보입니다. 실제 연결은 다음의 100g 수신 시험으로 확인합니다. 이미 등록한 키를 유지할 때는 키 입력칸을 비워 저장할 수 있습니다.

5. 세제 100g 상품 연결하기

중앙 관리로 돌아와 이 상품을 주문하면 입구 세제에 100g를 준비하도록 연결합니다.

  1. 현재 매장에서 성수점을 선택합니다.
  2. 상품 연결 → 상품 연결을 엽니다.
  3. 다음처럼 입력합니다.
입력칸 입력 예시
표시 이름 세제 100g
연결 기준 상품명
상품명 POS에 표시된 리필 테스트 100g
옵션명 (선택) 비워 둡니다.
리필 장치 입구 세제 · g
1개당 리필 용량 100
이 상품 연결 사용 체크
  1. 상품 연결을 누릅니다.
  2. 목록에서 세제 100g의 연결 값이 상품명: 리필 테스트 100g, 기기가 입구 세제, 용량이 100 g, 사용이 사용 중인지 확인합니다.

일반 POS 상품은 연결 기준: 상품명을 선택하고 POS에 보이는 상품명을 띄어쓰기까지 그대로 입력합니다. 예를 들어 POS 상품명이 리필 테스트 100g이면 상품명에 리필 테스트 100g, 1개당 리필 용량에 100을 입력합니다. 옵션이 있으면 옵션명 (선택)에 선택할 옵션명을 쉼표로 구분해 입력합니다.

상품 코드가 있는 상품은 연결 기준: 상품 코드를 선택하고 상품 코드 / 옵션 코드 (선택)에 해당 값을 입력합니다. 이미 등록된 상품 코드 연결은 같은 기준으로 표시됩니다.

같은 기기의 여러 상품은 1개당 용량 × 수량으로 합산합니다.

6. 100g 연결 시험하기

이 단계는 Toss 앱이나 결제 설정 없이 할 수 있습니다. 중앙 관리가 보낸 용량을 실제 기기가 받는지 확인합니다.

  1. 입구 세제 기기를 대기 상태로 둡니다.
  2. 중앙 관리에서 성수점을 선택하고 테스트 주문을 엽니다.
  3. 세제 100g의 수량을 1로 입력합니다. 다른 상품이 있으면 수량을 0으로 둡니다.
  4. 오른쪽 장치별 전달량에 입구 세제 · 100 g가 보이는지 확인합니다.
  5. 용량 전달을 한 번 누릅니다.

두 곳에서 결과 확인

확인할 화면 연결 성공 시 확인할 것
입구 세제 기기의 Display 리필을 준비해 주세요.와 준비량 100.0 g
입구 세제 기기의 Web 리필 화면 결제된 리필량 100 g
중앙 전달 대기 → 새로고침 입구 세제의 100g 대기 행이 사라짐. 빠르게 수신하면 대기 행이 처음부터 안 보일 수 있습니다.

기기가 받은 후 중앙 대기 목록에서 제거됩니다. 토출 완료는 실제 기기의 완료 화면에서 확인합니다.

연결 확인만 할 때는 기기 준비 화면의 취소 또는 준비 취소를 누릅니다. 실제 토출까지 확인할 때는 용기를 놓고 리필 시작을 누릅니다. 준비 화면은 설정된 시간 뒤 자동으로 닫히므로 전송 후 기기를 바로 확인하세요.

기기에 준비량이 안 보이면 중앙 전달 대기를 새로고침합니다. 대기 행이 남아 있으면 기기 연결 확인을 따릅니다. 대기 행이 비었으면 기기에서 준비 시간이 만료됐는지 먼저 확인합니다.

9. Toss POS 연결하고 결제 주문 확인하기

100g 연결 시험을 마쳤다면 해당 매장의 Toss POS를 연결합니다. 매장에서는 매장 ID 등록 → Open API 서비스 연결 → 완료 주문 확인 순서로 진행합니다. 서비스를 처음 설치하는 서버 운영자는 아래 처음 서버를 연결하는 담당자 안내를 먼저 완료합니다.

매장 ID와 서비스 코드 확인

필요한 값 어디서 받거나 확인하나요? 어디에 사용하나요?
Toss 가맹점 ID (MerchantId) 실제 매장은 서비스 연동 담당자에게 받습니다. 개발 매장은 개발자센터 테스트 가맹점 관리 → 해당 매장의 가맹점 ID (MerchantId) 값을 확인합니다. 중앙 매장 관리 → 해당 매장 수정 → 토스 가맹점 ID
Open API 서비스 코드 연동 담당자 또는 개발자센터 내 애플리케이션 → API 앱의 서비스 코드 해당 매장의 Toss POS 서비스 코드로 연결
  1. 전체 관리자가 중앙 현재 매장에서 성수점을 선택합니다.
  2. 매장 관리 → 성수점 수정 → 토스 가맹점 ID에 받은 MerchantId를 입력하고 변경 저장을 누릅니다. 수정 화면을 다시 열어 같은 값이 저장됐는지 확인합니다.
  3. 성수점의 Toss POS에서 설정 → 기타설정 → 서비스 연동 → 서비스 코드로 연결을 엽니다.
  4. 받은 Open API 서비스 코드를 입력해 연결하고 해당 서비스가 연결된 화면을 확인합니다.

MerchantId는 매장별 API 식별자입니다. POS 로그인에 사용하는 매장고유번호는 아래 개발 매장 로그인 단계에서 사용합니다.

공식 Open API 서비스 설치

완료 주문과 준비량 확인

중앙 상품 연결에서 POS의 리필 상품을 연결합니다. 일반 상품은 연결 기준: 상품명과 POS에 표시된 상품명을 입력합니다. 예: 리필 테스트 100g → 입구 세제 → 1개당 100. 상품 연결을 누른 뒤 목록의 상품명·기기·용량을 확인합니다. 상품 코드가 있는 상품은 연결 기준: 상품 코드를 선택합니다.

  1. 연결된 POS에서 등록한 리필 상품을 주문하고 결제를 완료합니다.
  2. 해당 매장의 실제 기기에 상품 용량 × 수량이 준비되는지 확인합니다.
  3. 중앙 전달 대기 → 새로고침으로 수신을 확인합니다.
  4. 용기를 놓고 기기에서 리필 시작을 누릅니다.
연결된 상품 예시 주문 수량 기기 준비량
같은 입구 세제의 100g 상품 10 1,000g
같은 입구 세제의 500g 상품 2 1,000g
위 두 상품을 한 주문에 함께 10 + 2 2,000g
입구 세제 100g + 안쪽 섬유유연제 100g 각각 1 각 기기에 100g씩

중앙 토스 서버 설정 있음은 아래 서버 설정 네 값의 등록 여부를 나타냅니다. 실제 완료 주문의 준비량까지 확인하면 매장 연동 점검을 마칠 수 있습니다. 준비가 안 되면 Toss 연결 문제를 확인하세요.

처음 서버를 연결하는 담당자: API 앱·인증 키·웹훅 설정

API 앱 만들고 인증 정보 받기

  1. Toss 개발자센터에 로그인하고 내 애플리케이션 → 생성하기를 엽니다. 기존 연동 API 앱을 사용하는 경우 해당 앱을 엽니다.
  2. 앱을 새로 만들 때 타입 API, 서비스 이름, 앱 ID, 회사명을 입력해 생성합니다. 앱 ID는 담당자가 정한 고유 문자열입니다. 저장 후 상세 화면의 ID와 서비스 코드를 확인합니다.
  3. API 앱의 인증 정보 → 생성에서 알아보기 쉬운 별칭을 입력하고 생성합니다.
  4. 표시된 Access Key와 Access Secret을 서버 비밀값 저장소에 보관합니다. Access Secret은 생성할 때 한 번 확인할 수 있습니다.

  2. 다음 값을 입력해 생성합니다.
입력칸 입력할 값

공식 웹훅 설정 안내

서버에 네 값 저장하기

서버 운영 담당자가 서버의 비밀값 설정에 다음 값을 저장합니다. 중앙 관리 웹에서는 매장·기기·상품을 설정하고, 아래 인증값은 서버 운영 환경에서 관리합니다.

서버 설정 이름 가져오는 값
TOSS_ACCESS_KEY API 인증 정보의 Access Key
TOSS_SECRET_KEY 같은 인증 정보의 Access Secret
TOSS_WEBHOOK_SECRET 위 웹훅의 Secret Key
TOSS_APP_ID 해당 API 앱의 ID 문자열. 실제 웹훅의 app 값과 일치하는 값

운영 서버가 Cloudflare Worker이면 해당 Worker의 Settings → Variables and Secrets에서 세 키를 비밀값으로 저장하고 앱 ID도 등록한 뒤 변경을 배포합니다. 위 값을 저장한 후 중앙 관리에 다시 접속해 토스 서버 설정 있음을 확인합니다. 이어서 대상 매장에서 서비스 코드를 연결하고 실제 완료 주문의 준비량을 확인합니다.

개발 테스트 매장 준비하고 POS 앱·현금 주문 시험하기

테스트 매장과 POS 로그인 정보 확인

  1. 개발자센터 테스트 가맹점 관리에서 시험할 기존 매장을 선택합니다. 새 매장이 필요하면 화면의 직접 만들기 또는 불러오기로 등록합니다.
  2. 해당 매장의 가맹점 ID (MerchantId) 값을 중앙 시험 매장의 토스 가맹점 ID에 입력·저장합니다.
  3. 매장 상세의 토스 POS/프론트 로그인 정보에서 매장고유번호·사업자등록번호·휴대폰번호를 확인합니다.
  4. Toss POS를 설치하고 이 정보를 입력해 테스트 매장으로 로그인합니다.
  5. 개발자센터의 같은 매장 상세에서 사용할 API 앱의 사용 여부를 ON으로 설정하고 저장된 상태를 확인합니다.

리필 코드 테스트 POS 앱 준비

리필 코드 테스트는 개발 담당자가 준비한 시험용 POS 앱입니다. 이 메뉴로 시험하려면 해당 시험 매장용 앱 파일과 매장 ID를 담당자에게 받습니다.

  1. 개발자센터 내 애플리케이션에서 시험용 POS 앱을 엽니다. 새 앱은 타입 포스, 이름, ID, 회사명으로 등록합니다.
  2. 앱 정보의 ACL (URL) 항목에 https://refill.endet.xyz를 등록하고 저장된 주소를 확인합니다. 이 앱의 서비스 코드는 앞의 Open API 앱과 별도로 확인합니다.
  3. 해당 앱의 테스트 단말기 관리 → 단말기 등록에 시험할 POS의 단말 식별자를 등록합니다. 단말 식별자는 설치 담당자와 해당 POS에서 확인하고, 등록 목록에 같은 값이 표시되는지 확인합니다.
  4. 개발 배포 → 개발용 파일 추가로 해당 시험 매장용 앱 파일을 올리고 배포합니다. 배포 목록에서 해당 버전이 배포됨인지 확인합니다.
  5. 테스트 가맹점 관리 → 해당 매장 → 애플리케이션에서 시험용 POS 앱의 사용 여부를 ON으로 설정합니다.
  6. Toss POS를 새로고침하거나 종료 후 다시 실행하고 좌측 상단 메뉴 → 기타설정 → 외부 서비스 설정 → 리필 코드 테스트가 보이는지 확인합니다.

현금 시험 주문

  1. 중앙 상품 연결에서 연결 기준: 상품 코드를 선택해 device-test-100g / 100g, device-test-500g / 500g 두 시험 상품을 같은 기기에 연결합니다.
  2. POS의 리필 코드 테스트를 열고, 기존 카테고리가 있는 할인 없는 빈 주문에서 100g × 10 · 1,000원을 누릅니다. 1종 주문 추가 완료 · 1,000원과 주문 수량 10을 확인합니다.
  3. POS 기본 결제에서 현금 → 현금영수증 미발급으로 해당 시험 주문을 완료합니다.
  4. 기기에 1,000g 준비·중앙 대기 삭제를 확인하고 기기에서 시작·완료를 확인합니다.
  5. 새 빈 주문으로 500g × 2 · 1,000원, 100g × 10 + 500g × 2 · 2,000원도 각각 1,000g·2,000g인지 확인합니다.

10. 평소 사용하기

리필 상품 결제 완료 → 기기 준비량 확인 → 용기 놓기 → 리필 시작 → 기기 완료 확인 순서로 사용합니다. 일시정지·재개·정지는 기존 기기의 리필 조작을 사용합니다.

스위치 운전을 설정한 기기는 준비 후 OFF → ON으로 시작합니다. 진행 중 OFF는 일시정지, 다시 ON은 남은 양 재개입니다. 준비량 수신 때 스위치가 이미 ON이면 먼저 OFF로 바꾼 후 ON으로 시작합니다. 완료 후에도 다음 사용을 위해 OFF로 돌립니다.

Display에서 다른 기능을 사용하려면 우측 상단을 5번 터치해 홈으로 돌아갑니다. 홈의 POS 버튼으로 POS 화면에 다시 들어갈 수 있습니다. 일반 리필과 기기 Web도 사용할 수 있습니다.

중앙 관리 목록은 새로고침으로 갱신합니다.

상품 용량이나 기기를 바꿀 때는 상품 연결 → 수정 → 변경 저장을 사용합니다. 이 상품 연결 사용을 해제하면 중지, 다시 선택하면 사용 중으로 바뀝니다. 앞으로 보낼 주문에 변경 내용이 적용됩니다.

정리할 항목 메뉴
기기 이름·표시 단위 리필 장치 → 수정 → 변경 저장
상품 연결 삭제 상품 연결 → 삭제 → 연결 삭제
빈 매장 삭제 매장 관리 → 삭제 → 매장 삭제. 기기가 등록된 매장은 먼저 설치 담당자와 정리 방법을 확인합니다.

11. 준비 시간과 취소

준비 자동취소는 기본 30초, 일시정지 자동취소는 기본 60초입니다. 두 시간 모두 1~3,600초로 설정할 수 있습니다.

설정할 화면 경로와 저장
Display 관리 화면 → 디스펜스 → 준비 자동 취소 / 일시정지 자동 취소 → 변경
기기 Web 제품·리필 → 리필 설정 → 준비 자동 취소 (초, 공통) / 일시정지 자동 취소 (초, 공통) → 리필 설정 저장

같은 설정이 일반·스위치·POS 리필에 적용됩니다. 준비 후 시작하지 않고 시간이 지나면 준비량이 해제됩니다. 기기를 재부팅해도 받은 준비량이 사라지므로 필요하면 담당자가 주문·기기 상태를 확인합니다.

취소할 대상 사용할 조작
중앙 전달 대기에 남은 양 전달 대기 → 미수신량 취소 → 미수신량 취소
기기에 이미 표시된 준비량 기기 준비 화면 취소 또는 준비 취소
진행 중인 리필 기기 정지
결제 취소·환불 해당 매장의 Toss POS에서 처리

POS 결제를 취소했을 때도 기기의 준비·진행 상태를 확인해 필요한 취소·정지를 함께 합니다. 중앙에서 미수신량을 취소한 뒤에는 새로고침으로 해당 행이 제거됐는지 확인합니다.

12. 잘 안 될 때

증상 바로 확인할 것
로그인 실패·만료 본인 로그인 ID와 비밀번호로 다시 로그인합니다. 비밀번호를 잊었거나 계정이 비활성화되어 있으면 전체 관리자에게 확인합니다. 시도 횟수 제한 안내가 나오면 10분 후 시도합니다.
상품 연결 버튼을 사용할 수 없음 현재 매장을 확인하고 리필 장치를 먼저 등록합니다.
100g 준비가 안 보이고 대기 행이 남음 실제 기기에서 기기 설정 → POS 연동을 열어 POS 사용·공통 서버 주소·그 기기의 키·인터넷 연결을 확인합니다.
대기 행은 사라졌으나 준비량이 안 보임 기기 준비 시간이 지났거나 취소·재부팅이 있었는지 확인합니다. 준비 화면이 남아 있으면 취소 후 새 시험을 합니다.
다른 기기에 양이 준비됨 상품 연결 → 수정에서 대상 기기를 확인하고, 두 실제 기기에 입력한 키가 각각 맞는지 확인합니다.
기존 미수신량 안내 전달 대기에서 해당 기기와 양을 확인하고 수신 또는 미수신량 취소 후 다음 주문을 진행합니다.
합산량 오류 1개당 용량과 수량을 확인합니다. 기기별 합산량은 최대 4,000입니다.
Toss 주문만 전달 안 됨 현재 매장의 MerchantId·Open API 서비스 연결·상품 연결 기준과 입력한 상품명/상품 코드·옵션을 확인하고 서버 연동 담당자에게 해당 주문을 확인받습니다.
토스 설정 필요 서버 운영 담당자에게 Toss 설정을 확인받습니다.
매장 ID 필요 전체 관리자가 매장 관리 → 수정에서 그 매장의 MerchantId를 저장합니다.
POS 지원 모델이 아닙니다. 설치 담당자에게 기기의 POS 지원 모델·펌웨어를 확인받습니다.

연결 키를 잃었거나 교체할 때

  1. 현재 매장에서 해당 매장을 선택합니다.
  2. 리필 장치에서 대상 기기의 연결 키 재발급 → 새 키 발급을 누릅니다.
  3. 새 키를 보관하고 해당 실제 기기의 POS 설정에 입력해 저장합니다.
  4. 앞의 100g 시험으로 연결을 다시 확인합니다.

재발급하면 이전 키와 연결이 종료됩니다. 키가 표시된 화면·파일은 관리자만 보관하고, 공유할 캡처에서는 키를 가립니다. 관리 작업을 마치면 로그아웃합니다.
